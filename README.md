# SQL Authentication Log Investigation

## Objective

Analyze authentication logs using SQL to identify suspicious
login activity, repeated failed attempts, and potentially
compromised accounts.

## Scenario

A company noticed an increase in failed login attempts.
As a security analyst, I investigated authentication records
using SQL to identify unusual login patterns and determine
which events required further investigation.

## Tools Used

- SQL
- SQLite
- CSV
- GitHub

## Investigation Goals

- Identify failed login attempts
- Find users with repeated authentication failures
- Identify suspicious IP addresses
- Investigate successful logins following failed attempts
- Document findings and security recommendations

## Key Findings

Investigation findings will be documented after analyzing
the authentication dataset.

## Recommendations

Recommendations will be based on the investigation results.
